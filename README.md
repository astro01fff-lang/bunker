## Мафия
Актуальная версия: https://astro01fff-lang.github.io/bunker/mafia/?v=1

Номер `?v=` в конце ссылки меняется при каждом обновлении игры, чтобы браузер не показывал старую сохранённую копию. Сотрудникам можно давать ссылку-приглашение из лобби игры.

Последнее обновление: 16.11.2026 — на сайте игра больше не переключается в демо-режим, если связь появилась не сразу; вместо этого показывает «Нет связи с сервером игры» и переподключается сама.
